# Global AI Investor（全球AI投资家）

面向 A 股的个人研究终端：**网络信息采集 → AI 分析/核验 → 每日看涨候选 → 模拟交易 → 一周结果复盘**。  
桌面端 Electron + React，后端 Python FastAPI（本地 sidecar），数据 SQLite；支持 DeepSeek 与本地 Ollama。

> 仅用于个人研究与模拟交易，不构成投资建议，不接真实券商下单。

## 功能

- **AI 模拟交易完整链路**：采集公告/新闻/全球公开信息 → AI 分析 → 生成含参考价/止损/止盈/数量的操作空间 → 独立模拟账户跟踪 → 5 个交易日后按真实日线评估。
- **AI 投资建议**：从带原文证据的新闻/公告分析中生成买入候选与持仓卖出/持有建议；无证据不生成结论。
- **AI 团队研判**：技术面/新闻面/风险三角色一次结构化输出，附技术指标、参考价与原文证据；编造证据直接拒绝。
- **技术指标**：本地日线计算 MA5/10/20/60、RSI14、MACD、布林带、KDJ、量比、ATR14。
- **全球公开信息**：PR Newswire、Google News、CNBC、MarketWatch、UN News 的出口/订单/合同类信息（只存标题/链接/摘要，未授权，仅供内部研究）。
- **信息核验**：来源等级、多源交叉印证、发布前后股价反应（上涨/下跌/提前异动/无反应/无数据）；不声称“证明真假”。
- **自动运行**：交易日 08:30 自动跑完整链路；09:35 按 READY 计划自动买入；交易时段每 30 分钟检查持仓，L3/L4 负向消息、-8% 止损、+8% 止盈、大盘急跌时自动卖出，并写入警报。
- **驾驶舱 / 新闻公告 / 警报中心 / 预测与准确率 / 设置**：7 个页面，精简导航。
- **规则引擎**：10 个交易规则版本（沪深北/ST/北交所），费用、T+1、涨跌停、申报单位均按规则版本计算。

## 页面

| 页面 | 作用 |
|---|---|
| 驾驶舱 | 指数、涨跌家数、涨跌停、成交额、AI 候选、警报、观察池、模拟资产 |
| 新闻公告 | 国内公告/新闻 + 全球公开信息 + 核验标签 |
| AI 投资建议 | 每日买入候选/持仓建议 + 团队研判 |
| 警报中心 | 持仓风险/卖出提醒，支持单条确认与全部确认 |
| 预测与准确率 | 推荐后是否上涨、命中率与误差统计 |
| AI 模拟交易 | 采集→分析→操作空间→一周模拟→评估 |
| 设置 | 中英文、AI Key（DPAPI 加密）、数据源说明 |

## 技术架构

```
Electron 33 + React 18 + TypeScript + Vite
        │
        └─ Python FastAPI sidecar（PyInstaller onedir）
              ├─ SQLite（WAL）
              ├─ 数据源：巨潮公告、RSS 新闻、全球公开 RSS、东财快照（未授权）
              ├─ AI：DeepSeek / 本地 Ollama
              └─ APScheduler：08:30 链路、09:35 自动买入、盘中 30 分钟风控
```

## 开发

```powershell
# 前端
npm install
npm run dev

# 后端（本地开发）
python -m uvicorn backend.app.main:app --host 127.0.0.1 --port 8000

# 测试
.venv\Scripts\python.exe -m pytest backend/tests -q
```

## 数据与合规

- 行情为第三方未授权快照（非实时），界面必须标注来源/时间，禁止宣称实时行情。
- 公告/新闻只存元数据/链接/摘要；全球公开源为公共 RSS，许可状态未确认，仅内部研究，不构成再分发授权。
- DeepSeek API Key 使用 Windows DPAPI 加密保存在本机，不写日志、不进 Git。
- 本项目不提供真实交易通道，所有买卖均为模拟。
