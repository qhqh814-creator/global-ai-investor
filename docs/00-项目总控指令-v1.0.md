## 1. 项目定位

Global AI Investor 是一款 **Windows 独立桌面应用**：面向中国 A 股市场，采集真实公开数据，用本地/云端 AI 做新闻与公告分析、股票初筛、公司情报、正反方研究、四级重大消息警报、买卖条件分析，并提供历史回测、模拟交易与历史预测准确率统计。中英文双语。

V1.0 只做 **中国国内 A 股市场**，不开发美国、香港市场的实际业务功能；架构保留市场扩展接口。

## 3. 不可违反的原则

### 3.1 事实真实性（最高优先级）

- **禁止虚构任何数据**。没有取得真实数据时，UI 显示“数据不可用 / Data unavailable”，禁止用占位数字、示例数字、随机数、插值、旧缓存冒充当前值。
- 每条行情/新闻/公告/财务数据必须可溯源：来源、原始 URL/接口、抓取时间、数据自身时间、许可状态。
- 免费数据不能满足实时要求时，如实标注“延时/收盘数据/第三方未授权快照”，**禁止**在任何位置写“实时”（除非未来接入并标定授权源）。

### 3.2 交易规则配置化、版本化

- 沪市主板、科创板、深市主板、创业板、北交所分别适配，不得统一按 10% 涨跌幅处理。
- 全部规则存于配置库，带**生效日期、废止日期、官方依据文号、来源 URL、版本号**；交易计算程序不得硬编码规则。
- 规则变化可更新；“已发布未实施/暂缓实施”的条款必须单独建模。
- 回测必须按交易日选择当日有效规则版本（time-travel）。

### 3.3 数据源独立适配器

- 每个数据源一个独立适配器，禁止在业务代码里直接散写 HTTP 请求。
- 适配器负责：限流、重试、缓存、字段归一化、来源标注、健康检查、降级。
- 数据源清单与许可状态以 04 号文档为准；新增数据源必须登记并评审许可。

### 3.4 本地 AI 与正式阶段大模型 API

- V1.0 开发/实验阶段：优先用本机 Ollama（RTX 4060 8GB，qwen3:8b 等）做可复现的本地 AI 实验。
- 正式阶段：接入 **DeepSeek API**（OpenAI 兼容接口），密钥本地加密保存（DPAPI），不得写入日志/代码仓库。
- AI 输出必须结构化（JSON schema 校验）并附证据引用（原文片段 + 来源 + 时间），禁止无依据编造结论。

### 3.5 桌面安装与 F 盘独立部署

- Windows 独立安装包（NSIS），安装/升级/卸载不影响用户数据。
- 项目根目录：`F:\GlobalAIInvestor`（代码、文档、运行时工具、虚拟环境）。
- 用户数据目录：`F:\GlobalAIInvestor\data`（数据库、缓存、日志、备份），可整体迁移/备份。
- 不得硬编码 C 盘路径；不得依赖系统全局安装的 Node/Python 运行（打包后自带运行时）。

### 3.6 项目保护规则

- 不删除、不覆盖用户已有数据；所有破坏性操作必须可回滚（见 08 号文档）。
- 数据库每次启动前自动备份，保留策略可配置。
- 代码与文档纳入 git 版本控制；重大变更需记录变更单。
- 不上传用户数据、行情数据、API 密钥到任何外部服务（仅用户主动配置的 AI API 调用除外，且只发送必要的分析文本）。

## 6. 变更管理

- 任何需求变更：在对应文档“变更记录”表登记（日期、变更项、原因、影响、批准人）。
- 规则/数据源变更额外要求：更新规则版本或数据源登记表，补测试用例。
- 版本号规则：文档 vX.Y；规则库 `rules-YYYY.MM.DD.N`；应用语义化版本。

## 7. 术语

| 术语 | 含义 |
|---|---|
| 快照 | 某一时刻抓取的行情数据（可能是收盘/延时） |
| 数据不可用 | 未取得真实数据时的唯一合法展示状态 |
| 规则版本 | 一组带生效区间的交易规则参数 |
| 暂缓实施 | 规则已发布但条款尚未生效（如北交所盘后固定价格交易） |
| time-travel 回测 | 按历史交易日选择当日有效规则版本进行回测 |
| provenance | 数据溯源信息（来源/时间/许可/实时性） |
