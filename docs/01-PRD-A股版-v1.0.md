## 1. 产品目标与用户

### 1.1 目标

为个人投资者提供一个 **Windows 本地桌面** 的 A 股研究终端：真实数据 + AI 分析 + 规则化回测/模拟交易，帮助用户理解消息面、形成可验证的买卖条件，并持续统计预测准确率。

### 1.2 用户

- 主要用户：具备 A 股基础知识的个人投资者（本项目所有者）。
- 使用场景：每个交易日盘后复盘；盘前阅读公告/新闻与警报；对观察池股票做正反方研究；用回测验证策略；用模拟账户跟踪信号。
- 语言：中文（默认）/ English，可切换。

### 1.3 成功标准（V1.0）

- 干净 Windows 机器上可通过安装包安装、启动、离线查看已有数据。
- 驾驶舱每个指标均可追溯到真实数据源；无法获取时正确显示“数据不可用”。
- 规则引擎可按板块/日期正确计算涨跌停、费用、申报校验、T+1、盘后固定价格可用性。
- 回测跨越 2026-07-06 规则变更时自动切换 ST 涨跌幅与盘后交易规则。
- 四级警报、买卖条件、预测记录与准确率可查询。

## 2. 范围

### 2.1 范围内

A 股五板块（沪主板、科创板、深主板、创业板、北交所）的：基础信息、行情（按许可如实标注）、公告、新闻、财务数据；AI 新闻分析、初筛、公司情报、正反方研究、四级警报、买卖条件；回测；模拟交易；预测准确率。

### 2.2 范围外（V1.0）

美股/港股全部功能；实盘交易；Level-2 行情；移动端；云同步；海外数据源；自动下单。

## 4. 驾驶舱需求（Dashboard）

驾驶舱只显示以下内容；每张卡片必须带：**数据来源、数据时间、实时性标注**；无数据显示“数据不可用 / Data unavailable”。

| # | 卡片 | 数据要求 | 不可用状态 |
|---|---|---|---|
| D1 | 上证指数 | 指数点位、涨跌幅、数据时间 | 数据不可用 |
| D2 | 深证成指 | 同上 | 数据不可用 |
| D3 | 创业板指 | 同上 | 数据不可用 |
| D4 | 科创50 | 同上 | 数据不可用 |
| D5 | 北证50 | 同上；仅在取得数据时显示（默认第三方源，标明来源） | 数据不可用（或按配置隐藏） |
| D6 | 沪深北市场行情 | 涨跌家数、成交额、涨跌分布（必须有真实数据） | 数据不可用 |
| D7 | A股涨跌家数 | 上涨/下跌/平盘家数 | 数据不可用 |
| D8 | 涨停/跌停家数 | 涨停数、跌停数（按当日规则判定） | 数据不可用 |
| D9 | 成交额 | 沪深北合计成交额 | 数据不可用 |
| D10 | 重大利好消息 | AI 从新闻/公告提取，附来源与时间 | 数据不可用/无消息 |
| D11 | 重大风险警报 | L1–L4 警报摘要 | 数据不可用/无警报 |
| D12 | AI 投资机会 | 初筛结果与理由 | 数据不可用/无结果 |
| D13 | 股票观察池 | 自选股列表与最新数据 | 数据不可用 |
| D14 | 买卖信号 | 信号列表与触发条件 | 数据不可用 |
| D15 | 模拟账户资产 | 总资产、可用资金、持仓市值、当日盈亏 | 数据不可用 |

**硬性规则（验收项）**：
- 任何数字不得来自占位/随机/硬编码；测试中关闭全部数据源时，所有卡片必须显示“数据不可用”。
- 非交易日显示“最近交易日 YYYY-MM-DD 收盘”，禁止显示“实时”。
- 第三方未授权数据必须显示来源徽标与“第三方快照，非实时”。

## 5. 功能需求（15 项交付目标）

### FR-01 Windows 桌面安装与启动
- NSIS 安装包；安装后双击启动；启动时自检数据库/备份/环境；离线可查看历史数据。
- 验收：干净机安装→启动→主界面加载；卸载后用户数据保留（可配置删除）。

### FR-02 中英文双语
- 全部 UI 文案、错误提示、数据不可用原因、免责声明支持 zh-CN / en-US；默认中文；切换即时生效；规则/数据源专有名词保留官方原文。
- 验收：语言切换无遗漏（i18n key 覆盖率 100%）。

### FR-03 A股三所五板块股票基础信息
- 证券列表：代码、名称、交易所、板块、证券类型、上市日期、状态（正常/ST/*ST/退市整理/停牌）、总股本等可得字段。
- 数据来源与更新记录可见；缺失字段显示“—”。
- 验收：至少覆盖沪深北在市的 A 股股票；字段来源可追溯。

### FR-04 真实新闻和公告采集
- 公告：巨潮资讯（沪深北覆盖）；新闻：合法公开源（如中新网财经 RSS、政府网站栏目）。
- 采集必须遵守许可；新闻只存标题+链接+≤100字摘要；公告存元数据与原始链接。
- 验收：可查询最近 N 天公告/新闻；每条有来源与时间；失败有原因码。

### FR-05 真实行情数据接入
- 指数与个股快照/日K；来源：第三方快照（明确标注未授权/非实时），预留授权源。
- 字段含 quote_time、fetched_at、is_realtime、license_status、data_unavailable_reason。
- 验收：断网/源失败时显示“数据不可用”，绝不使用旧值冒充。

### FR-06 财务数据采集
- 公告驱动的财务报告（年度/季度）与关键指标（营收、净利、EPS、ROE 等）；来源可追溯；无数据显示“—”。
- 验收：可查看单公司财务摘要与报告链接。

### FR-07 本地 AI 新闻分析
- 输入新闻/公告文本，输出结构化 JSON：事件类型、涉及股票、情感、重要性（L1–L4）、摘要、证据引用。
- 实验阶段使用 Ollama；正式阶段使用 DeepSeek API；两者可切换。
- 验收：每条分析有证据片段与来源；无模型时显示“AI 服务不可用”，不伪造分析。

### FR-08 股票初筛
- 条件：规则型（涨跌幅、量比、成交额、市值、板块、ST 状态等）+ AI 摘要理由；结果可解释、可保存。
- 验收：初筛结果每项可追溯到数据；无数据时不出结果。

### FR-09 公司情报档案
- 单公司：基础信息、公告时间线、新闻、财务、股东/行业（可得时）、AI 摘要。
- 验收：档案中的每条信息带来源与日期。

### FR-10 正反方 AI 研究
- 给定股票/事件，输出“多方论点/空方论点/关键分歧/待验证事实”，每条附来源。
- 验收：禁止无引用结论；可导出报告。

### FR-11 四级重大消息警报
- L1（关注）/L2（重要）/L3（重大）/L4（紧急）；规则可配置；触发记录含证据。
- 验收：警报可回溯到原始新闻/公告；级别定义见设置页。

### FR-12 买入和卖出条件分析
- 用户可定义条件（技术/基本面/消息面），系统按规则版本与数据计算是否满足；输出条件明细。
- 验收：条件计算可复现；数据缺失时标记“无法判定”。

### FR-13 历史回测
- 支持区间、股票池、规则版本感知（time-travel）、T+1、费用、涨跌停不可成交、停牌。
- 输出：收益曲线、回撤、胜率、交易明细、规则版本使用记录。
- 验收：跨 2026-07-06 回测自动切换 ST 涨跌幅/盘后交易可用性；结果可复现。

### FR-14 模拟交易
- 本地模拟账户：初始资金、下单校验（数量/价格/涨跌停/价格笼子/T+1/ST限购）、成交模型、持仓、净值。
- 验收：涨停买不到、跌停卖不出、T+1 当日买入不可卖等场景有测试用例。

### FR-15 历史预测准确率统计
- 记录 AI/信号预测（方向、区间、置信度），到期自动结算；统计准确率、命中率、按来源/模型/板块分组。
- 验收：可导出明细；未到期预测不参与统计。

## 6. 交易规则需求

见 06 号文档。PRD 层面要求：
- 五板块分别配置；不得统一 10%。
- 规则带版本与生效日期；2026-07-06 新规（沪深主板 ST 10%、盘后固定价格扩容至全部 A 股及 ETF）必须体现在引擎中。
- 北交所盘后固定价格交易在 2026-11-08 为“待实施”，引擎默认不可用。
- 费用：印花税卖出 0.05%、过户费 0.001% 双向、经手费沪深 0.00341% / 北交所 0.0125%、证管费 0.002%，佣金可配置。

## 7. 数据真实性需求

见 07 号文档。PRD 层面要求：所有卡片/表格/图表均受“数据不可用”与溯源约束；验收测试包含“全数据源关闭”场景。

## 8. 非功能需求

| 类别 | 要求 |
|---|---|
| 性能 | 冷启动 ≤ 5s；驾驶舱在本地数据就绪时 ≤ 2s 渲染；采集任务不阻塞 UI |
| 离线 | 无网络时可用历史数据；明确提示“当前离线” |
| 安全 | API 密钥 DPAPI 加密；日志脱敏；不上传用户数据 |
| 可靠性 | 采集失败重试+降级；数据库每日备份；崩溃可恢复 |
| 兼容 | Windows 10/11 x64；安装包未签名时提示用户风险 |
| 可维护 | 规则/数据源配置化；模块解耦；单元测试覆盖核心规则 |
| i18n | zh-CN / en-US 全量 |

## 9. 验收标准（摘要）

1. 安装/启动/卸载测试通过。
2. 关闭全部数据源时，驾驶舱 15 张卡片全部显示“数据不可用”（自动化测试）。
3. 规则引擎测试：五板块涨跌幅/ST/新股/申报/费用/盘后固定价格/T+1 全覆盖。
4. 2026-07-05 与 2026-07-06 两日 ST 规则切换测试通过。
5. 北交所盘后固定价格默认不可用测试通过。
6. 回测 time-travel 测试通过。
7. 预测准确率统计可复现。
8. 中英文切换无遗漏。

## 10. 风险

| 风险 | 影响 | 缓解 |
|---|---|---|
| 免费行情源不稳定/条款风险 | 行情展示受限 | 多源降级；明确标注；预留授权接口 |
| 规则细节未逐字核验（docx 附件） | 计算偏差 | P1 逐条核验门禁；测试用例 |
| 本地 AI 速度/显存不足 | 分析慢 | 8B 量化模型；任务队列；可切换 DeepSeek API |
| 无代码签名证书 | SmartScreen/360 拦截 | 自签名测试；文档说明；后续可购证书 |
| 未签名安装包被杀软误杀 | 无法启动 | 本机实测；提供 SHA256；用户加白名单 |
