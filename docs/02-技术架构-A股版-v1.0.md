## 2. 技术选型与理由

| 层 | 选择 | 理由 |
|---|---|---|
| 桌面壳 | Electron 33+（或最新 LTS） | Windows 成熟、React 生态、NSIS 打包、本项目历史经验 |
| 前端 | React 18 + TypeScript + Vite | 组件化、类型安全、构建快 |
| UI | 自研轻量组件 + 图表库（ECharts） | 驾驶舱/回测曲线需求；许可友好 |
| 状态 | Zustand + TanStack Query | 轻量、缓存/重试清晰 |
| i18n | i18next（zh-CN/en-US） | 文案集中管理、覆盖率检查 |
| 后端 | Python 3.12 + FastAPI + Uvicorn | 数据/AI/回测生态；与现有 Python 能力匹配 |
| ORM/DB | SQLAlchemy 2 + SQLite WAL | 单机零运维、事务可靠、便于备份 |
| 调度 | APScheduler（进程内） | 采集任务定时；避免额外服务 |
| AI | Ollama（实验）+ DeepSeek API（正式） | 本地可复现；正式阶段稳定 |
| 打包 | electron-builder（NSIS）+ PyInstaller | 缓存已有 NSIS/签工具；无 VS Build Tools 也可用 prebuilt |
| 测试 | Vitest（前端）+ pytest（后端） | 与栈匹配 |
| 版本控制 | git | 项目保护、变更追踪 |

> 备选（已评估不采用）：Tauri（缺 Rust/MSVC，WebView2 已有也不划算）；PySide6 单进程（UI 工作量大，已确认 Electron 方案 A）。

## 3. 进程与安全模型

- **Electron main**：创建窗口、启动/监控 Python sidecar、崩溃重启、备份、日志、更新检查。
- **preload**：仅暴露白名单 IPC（`backend.info`、`app.version`、`dialog.*`），不暴露 Node API 给渲染进程。
- **renderer**：只通过 HTTP 访问 sidecar；开启 `contextIsolation`、禁用 `nodeIntegration`、CSP 白名单。
- **sidecar**：仅监听 `127.0.0.1`，端口随机；启动时生成一次性 Bearer Token，写入 main 进程内存并传给 renderer；请求头校验。
- **密钥**：DeepSeek API Key 用 Windows DPAPI（Python `win32crypt`）加密存于 `data/settings/secrets.dat`；日志脱敏。
- **数据**：全部本地存储；不上传；AI 调用只发送待分析文本（用户可在设置页预览发送内容）。

## 5. 数据流

1. **采集**：Scheduler 按任务表触发适配器（限流、重试、超时）→ 原始响应 → 归一化 → 写 `data_fetch_log`。
2. **入库**：Repository 写入行情/公告/新闻/财务表，强制写入 provenance 字段（见 07）。
3. **分析**：AI 队列读取新增新闻/公告 → 结构化分析（本地 Ollama 或 DeepSeek）→ `ai_analysis` + 证据。
4. **展示**：前端通过 sidecar API 查询；所有数值响应包含 provenance；前端组件 `DataCard` 统一渲染不可用/延迟徽标。
5. **模拟/回测**：读取行情与规则版本 → 撮合/校验 → 写结果表 → 前端展示。

## 6. 规则引擎设计

### 6.1 选择算法（伪代码）

```
def resolve_rule(exchange, board, security_type, risk_flag, listing_phase, trading_date):
    candidates = rule_sets where exchange/board/security_type match
                 and effective_from <= trading_date
                 and (effective_to is null or trading_date <= effective_to)
                 and clause_status == EFFECTIVE
    if empty: raise RuleNotFound (禁止默认 10%)
    choose most specific: risk_flag/listing_phase 专用优先于 NORMAL
    return rule_set (含 version_id, doc_no, source_url)
```

### 6.2 关键约束

- 禁止在代码中写死涨跌幅/费用/数量；全部来自规则库。
- 规则库加载时做 JSON Schema 校验；缺失必填参数拒绝启动该规则集。
- “暂缓实施”条款（北交所盘后固定价格等）以 `clause_status = PENDING` 存储，引擎按 `enabled` 判断。
- 回测按交易日逐日解析规则版本，跨 2026-07-06 自动切换。
- 所有规则计算输出 `rule_version_id` 并写入结果表，便于复现与审计。

### 6.3 校验与撮合边界

- 申报校验：数量（最小/递增/最大/零股一次性）、价格 tick、涨跌幅、价格笼子、板块交易时段、T+1 可卖数量、ST 单日买入上限、盘后固定价格可用性。
- 撮合（回测/模拟）：涨停价买入不保证成交、跌停价卖出不保证成交；按对手盘可成交量/排队模型简化实现并在文档标注假设。
- 收盘集合竞价 14:57–15:00 不可撤单；盘后固定价格 15:05–15:30 以收盘价成交（沪深已实施，北交所 PENDING）。

## 7. 数据源适配器层

```python
class SourceAdapter(Protocol):
    source_id: str
    capabilities: set[str]        # calendar, quote, announcement, news, financial, macro
    latency_class: str            # realtime_licensed | delayed | eod | unknown
    license_status: str
    commercial_ok: bool
    def health(self) -> HealthStatus: ...
    def fetch(self, request: FetchRequest) -> FetchResult: ...   # normalized records + provenance
```

- Registry 按 capability + 优先级选择；失败自动降级（L0→L4）。
- 全局令牌桶限流（默认 ≤1 req/s/源），指数退避，夜间低峰批量任务。
- 适配器不得绕过反爬（不破解 JS 挑战、不伪造 Cookie）。
- 抓取结果统一写 `data_fetch_log`（状态/耗时/错误码/样本哈希）。

## 8. AI 子系统

| 项 | 设计 |
|---|---|
| 本地实验 | Ollama `127.0.0.1:11434`，默认 `qwen3:8b`；超时与显存保护；模型不可用时禁用 AI 功能并提示 |
| 正式阶段 | DeepSeek API（OpenAI 兼容 `/chat/completions`）；密钥 DPAPI；可配置 model/temperature |
| 输出契约 | 严格 JSON schema：`{event_type, stocks[], sentiment, materiality(L1-L4), summary, evidence[{quote, source_url, published_at}]}`；解析失败重试一次后标记失败 |
| 防编造 | 仅允许引用输入文本；无证据不得输出结论；UI 展示证据与来源 |
| 队列 | `ai_tasks` 表 + 单并发（本地）/可配置并发（API）；失败重试与降级 |
| 成本 | API 调用计数与预算上限（设置页） |

## 9. 回测与模拟交易

- 回测：区间、股票池、初始资金、佣金/滑点、规则版本感知；输出指标（总收益、年化、最大回撤、胜率、盈亏比、交易明细、规则版本记录）。
- 模拟交易：账户、订单（限价/市价按板块可用类型）、撮合（简化的连续竞价模型）、持仓/成本、每日净值；与真实规则校验一致。
- 预测准确率：记录预测（方向/区间/置信度/模型/来源）→ 到期结算 → 统计（总准确率、按模型/板块/时间）。

## 10. 错误处理与降级

| 场景 | 行为 |
|---|---|
| sidecar 启动失败 | Electron 显示错误页 + 日志路径 + 重试按钮；不白屏 |
| 数据源失败 | 降级链；仍失败则“数据不可用” + 原因码；不使用旧值 |
| AI 不可用 | 相关卡片显示“AI 服务不可用”；其他功能继续 |
| 数据库损坏 | 启动前备份 + 完整性检查；损坏时提示从备份恢复 |
| 网络离线 | 显示“离线”；后台任务暂停；本地历史数据可查 |

## 12. 安全与合规

- 不绕过数据源反爬；遵守 robots/服务条款；第三方未授权数据仅内测/演示并明示。
- 新闻仅标题+链接+摘要；公告存元数据与原始链接，不再分发 PDF 原文。
- 无遥测；日志脱敏；发布构建校验 `commercial_ok=false` 数据源不得对外。
- 免责声明常驻设置页与关于页。
