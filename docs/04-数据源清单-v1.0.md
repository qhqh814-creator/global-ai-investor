## 1. 结论摘要

1. **免费合法的实时行情不存在**：上交所 Level-1 展示许可 15 万/年 + 用户使用费 15 万/年（≥30 万/年）；深交所 Level-1 网页/电脑/无线各 30 万/年。免费网站均为未授权快照，且官方未标注延迟分钟数 → `delay_seconds = null`，禁止写“延迟 15 分钟”。
2. **可稳定免费获取的是“非行情”数据**：深交所交易日历 API（唯一实测可用的官方日历）、巨潮公告 POST（单日 1104 条）、央行官方 RSS、中新网财经 RSS、政府网站栏目页。
3. **官方 API 普遍不可靠**：上交所公告 API 返回空；交易统计字段空；北交所公告/日历/指数接口 404；统计局 data 子站 403 WAF；gov.cn 政策文件库 403。

## 5. 合规风险与硬性禁令

| 风险 | 依据 | 处置 |
|---|---|---|
| 第三方行情再分发 | 东财 ToS 六.2：未经交易所书面同意不得复制/提供行情数据 | 仅内测/演示；对外版本不得启用；发布构建校验 |
| 实时性虚假宣传 | 官方未标注延迟 | `is_realtime` 仅授权源可为 true；文案禁用“实时” |
| 新闻全文抓取 | 著作权法；东财 ToS 六.1 | 仅标题+链接+≤100字摘要 |
| 公告 PDF 再分发 | 巨潮仅免责声明、无授权 | 仅存元数据+原始链接 |
| 反爬绕过 | BSE/统计局有挑战/WAF | 不绕过；失败即记录 |
| 限流/封 IP | 统计局重试后超时 | 全局令牌桶 + 指数退避 + 夜间批量 |

## 6. 抓取规范（适配器通用）

1. 统一 User-Agent（标明项目与联系邮箱），不伪装浏览器指纹以外的手段。
2. 全局限流：默认每源 ≤1 req/s，突发 ≤3；重试 3 次指数退避（1s/4s/16s）。
3. 超时：普通 15s；gov.cn 30s；巨潮 30s。
4. 失败分类：`upstream_403`、`waf_blocked`、`nontrading_day`、`interface_deprecated`、`rate_limited`、`parse_failed`。
5. 每次抓取写 `data_fetch_log`；连续 3 次失败标记源 DEGRADED 并告警（应用内）。
6. 缓存：行情快照不缓存冒充新值；公告/新闻按 URL/hash 去重。
7. 不得绕过验证码/JS 挑战/登录；不得调用付费接口。

## 7. 降级链

```
L0 licensed_feed（未采购，默认关闭）
 → L1 eastmoney_quote（主选，未授权快照）
 → L2 tencent_quote（failover）
 → L3 eod_close（上一交易日收盘，来自日K/巨潮）
 → L4 数据不可用（带原因码）
```

- 每个数据卡片/字段都必须能回答“当前处于哪一级、数据时间是什么”。
- 非交易日统一展示“最近交易日 YYYY-MM-DD 收盘”。
