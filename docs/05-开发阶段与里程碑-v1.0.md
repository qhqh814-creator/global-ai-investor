## 3. P1 规则引擎与基础数据（2.5–3 周）

### 任务
1. 规则库 schema + 加载器 + JSON Schema 校验。
2. 录入 2026 现行规则（沪/深/北）与历史规则（2023 版）：
   - 涨跌幅、ST、新股、退市整理、盘后固定价格、申报数量/上限、价格笼子、交易时段、T+1、费用、风险警示买入上限、临时停牌。
3. 交易日历（深交所 API + 三所年度休市公告核对，2023–2026 历史日历补齐）。
4. 证券主数据（三所列表；北交所注意过滤新三板代码）。
5. 申报校验器、费用计算器、时段/竞价校验器。
6. 规则原文核验门禁：下载三所规则 docx/PDF 存档，逐条核对“待核”项（主板新股临停、深主板市价上限、科创/创业价格笼子宽免、增发首日、北交所经手费）。
7. 单元/回归测试：
   - 2026-07-05 ST=5% vs 2026-07-06 ST=10%（沪深主板）
   - 科创板 200 股起 1 股递增；北交所 100 股起 1 股递增
   - 北交所盘后固定价格 `enabled=false`
   - 印花税/过户费/经手费计算
   - 价格笼子边界
   - T+1 可卖数量

### 出口条件
- 规则测试覆盖率 ≥ 90%（核心计算 100%）；
- 所有规则参数可从 DB 追溯 `rule_version_id` + 官方 URL；
- “待核”清单清零或明确记录为“已确认不适用”。

### P1 实现状态（2026-11-08）
- [x] 规则库 JSON 文件：SSE/SZSE 各 3 个版本（2023.02.17、2023.08.28、2026.07.06），BSE 4 个版本（2021.11.15、2023.08.28、2026.07.06、2026.08.31），共 10 个版本文件。

- [x] 费用计算（印花税/过户费/经手费/证管费/佣金，分版本费率）与涨跌停价四舍五入。
- [x] 申报校验器（数量/递增/上限/零股/T+1/价格笼子/涨跌幅/新股首日/盘后固定价格/风险警示买入上限/风险警示限价委托）。
- [x] 交易日历：深交所官方 API 适配器 + SQLite 存储；已同步 2026 全年 365 天（含 2026-10 国庆 7 天休市校验）。

## 4. P2 采集层（2 周）

### 任务
1. SourceAdapter 接口 + 注册表 + 令牌桶 + 重试 + 健康检查。
2. 适配器：
   - 行情：东财（主）、腾讯（备）、北交所 JSONP（北交所专用）；
   - 公告：巨潮；
   - 新闻：中新网 RSS、央行 RSS、证监会/政府栏目；
   - 日历：深交所 API；
   - 宏观：央行汇率页、统计局新闻页。
3. 归一化字段 + provenance 强制写入。
4. 每日调度（APScheduler）：盘前/盘后任务；非交易日处理。
5. 降级链 L0–L4 与 `data_availability` 更新。
6. 采集日志与失败原因码。

### 出口条件
- 全源关闭测试：驾驶舱所有卡片显示“数据不可用”；
- 单源失败测试：自动降级且 UI 标注正确；
- 连续 3 日采集成功率 ≥ 95%（本地可测范围内）。

## 5. P3 AI 分析（2 周）

### 任务
1. Ollama 客户端（超时/健康检查/模型缺失处理）；DeepSeek 客户端占位（密钥 DPAPI）。
2. 新闻/公告 → 结构化分析（event_type、stocks、sentiment、materiality、summary、evidence）。
3. 股票初筛（规则 + AI 摘要）。
4. 公司情报档案聚合。
5. 正反方研究（bull/bear/disputes/evidence）。
6. L1–L4 警报规则与触发记录。
7. 证据引用校验：无来源不出结论；JSON schema 校验失败重试一次。

### 出口条件
- 50 条样本新闻分析结果 100% 带证据引用；
- 模型不可用时全链路降级不崩溃；
- 警报可回溯到原文/公告。

## 6. P4 驾驶舱与交易辅助（1.5 周）

### 任务
1. 驾驶舱 15 张卡片（复用 DataCard/ProvenanceBadge 组件）。
2. 观察池管理。
3. 买卖条件规则与信号展示。
4. 中英文文案全量 + i18n 覆盖率检查。
5. 模拟账户资产卡片。

### 出口条件
- 卡片状态矩阵测试（可用/降级/不可用/离线/非交易日）通过；
- 语言切换无遗漏。

## 7. P5 回测与模拟交易（2 周）

### 任务
1. 回测引擎（按日解析规则版本、T+1、费用、涨跌停不可成交、停牌）。
2. 简化撮合模型与假设文档。
3. 模拟账户/订单/成交/持仓/净值。
4. 预测记录与到期结算、准确率统计。
5. 跨 2026-07-06 规则变更专项回测测试。

### 出口条件
- 相同输入两次回测结果完全一致（可复现）；
- 专项测试通过：ST 5%→10% 切换、盘后固定价格可用性切换。

## 8. P6 打包与验收（1.5 周）

### 任务
1. PyInstaller 打包 sidecar；electron-builder NSIS 安装包。
2. 应用图标/关于页/免责声明。
3. 干净机（或新用户配置）安装、启动、卸载验证。
4. F 盘独立部署验证：数据目录、备份、迁移。
5. 未签名安装包的 SmartScreen/360 提示说明与 SHA256 发布。
6. 验收清单执行并输出报告。

### 出口条件
- 安装包可安装、可启动、可卸载且用户数据保留；
- 验收清单全部通过或登记例外并说明。

## 11. 风险登记

| 风险 | 概率 | 影响 | 缓解 |
|---|---|---|---|
| 规则 docx 细节与网页摘要不一致 | 中 | 计算偏差 | P1 原文核验门禁；测试用例 |
| 第三方行情接口变更 | 中 | 行情不可用 | 多源降级；适配器隔离 |
| 本地 AI 显存不足/速度慢 | 中 | 分析慢 | 8B 量化；任务队列；可切 DeepSeek |
| 无代码签名 | 高 | 安装提示 | 自签名/说明文档；后续购证书 |
| 打包后 Python sidecar 被杀软拦截 | 中 | 无法启动 | PyInstaller onedir；本机实测；白名单说明 |
| 数据源许可纠纷 | 低 | 合规风险 | 仅内测使用；公开版切换授权源 |
