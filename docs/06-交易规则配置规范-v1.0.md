## 1. 设计原则

1. **禁止硬编码**：引擎代码中不得出现 10%、20%、30%、0.05% 等业务数字；全部从规则库读取。
2. **版本化**：每条规则带 `version_code`、`doc_no`（官方文号）、`effective_from`、`effective_to`、`source_url`、`checksum`。
3. **可回测**：按交易日解析当日有效版本；跨变更日自动切换。
4. **暂缓实施建模**：`clause_status = PENDING` 表示规则已发布但未生效（北交所盘后固定价格交易）。
5. **可审计**：所有计算结果记录 `rule_version_id`。

## 3. 参数清单（引擎必须支持）

### 3.1 版本与范围
`version_code`、`exchange`、`board`、`security_type`、`risk_flag`（NORMAL/ST/\*ST/DELISTING）、`listing_phase`（IPO_DAY1 / IPO_DAY2_5 / SEASONED）、`doc_no`、`publish_date`、`effective_from`、`effective_to`、`supersedes`、`source_url`、`checksum`、`clause_status`。

### 3.2 涨跌幅
`price_limit.type`（PCT/NONE/FIRST_DAY_SPECIAL）、`up_pct`、`down_pct`、`first_day_up_pct`、`first_day_down_pct`、`no_limit`、`rounding`（HALF_UP_TO_0.01）、`base_price_type`（PREV_CLOSE / ISSUE_PRICE / EX_RIGHTS_PRICE）、`risk_warning_buy_daily_cap`。

### 3.3 交易时段
`open_auction`、`open_auction_cancel_cutoff`（09:20）、`continuous`、`close_auction`（14:57–15:00，不可撤）、`after_hours`（enabled/trade time/order time/price type/min qty/step/max qty）、`market_order_types`、`market_order_only_with_limit`、`market_order_price_protection`。

### 3.4 申报
`min_qty`、`step`、`multiple_required`、`max_qty`、`max_qty_market`、`odd_lot_threshold`、`odd_lot_one_order`、`tick_size`。

### 3.5 价格笼子
`enabled`、`pct`、`abs_offset`、`compare`（WIDER/HIGHER_ONLY）、`base_price_type`（BEST_OPPOSITE/LAST/PREV_CLOSE）、`applies_sessions`（CONTINUOUS only）。

### 3.6 费用
`stamp_duty`（卖出单边）、`transfer_fee`（双向）、`handling_fee`（双向）、`regulatory_fee`（双向）、`commission_rate`（券商参数）、`commission_min`（默认 5 元）、`fund_handling_fee`、`cb_handling_fee`、`rounding_policy`。

### 3.7 结算
`settlement_cycle`（STOCK: T+1；ETF/可转债按品种）、`margin_eligible`。

### 3.8 特殊事件
`intraday_halt`（无涨跌幅股票 ±30%/±60% 停 10 分钟、14:57 复牌）、`delisting_first_day_no_limit`、`ex_rights_formula`、`abnormal_volatility`、`severe_abnormal_volatility`（北交所）。

## 5. 版本选择算法

```
rule = select(exchange, board, security_type, risk_flag, listing_phase, trading_date)
  1) 过滤：effective_from <= date and (effective_to is null or date <= effective_to) and clause_status= EFFECTIVE
  2) 优先级：risk_flag 专用 > listing_phase 专用 > NORMAL
  3) 无匹配 → RuleNotFound 异常（禁止回退到默认 10%）
  4) 记录 rule_version_id 随计算结果
```

- 回测逐交易日调用；跨日自动切换。
- 申报校验必须在“当日时段 + 当日规则版本”下进行。
- 盘后固定价格：`after_hours.enabled` 为 false 时拒绝该委托。

### 6.2 仍未核实（不得作为已确认事实）

1. **沪深主板新股上市首日 44%/36% 与临时停牌细节**：交易规则正文不含该细则，需另行核验上交所 2014-06-13《关于新股上市初期交易监管有关事项的通知》及深交所对应细则。
2. **科创板/创业板退市整理期次日起涨跌幅**（推断为 20%）。
3. **增发股票上市首日涨跌幅**（沪深规则未明文；北交所明文30%）。
4. **北交所经手费 0.0125%、证管费口径**：需下载北证公告〔2023〕54号及收费表原文核验。
5. **佣金上限 3‰、起点 5 元**：需券商监管规定原文。
6. **北交所盘后固定价格交易实施公告**：截至 2026-11-08 未见，保持 `PENDING`。
7. **北交所风险警示股票涨跌幅 30%**：第4.5节未另设比例，按 3.3.11 通用30%推定（高置信）。

## 8. 测试用例（必须全部通过）

1. 2026-07-03（周五）沪主板 ST 股票涨跌幅 = 5%（2023 版规则）。
2. 2026-07-06（周一）沪主板 ST 股票涨跌幅 = 10%（2026 版规则）。
3. 同期深主板 ST：5% → 10%。
4. 科创板 ST：20%（2023/2026 均同）。
5. 创业板 ST：20%。
6. 北交所 ST：30%；2026-08-30 无 20 万股上限、2026-08-31 起有。
7. 科创板买入 150 股 → 拒绝（min 200）；201 股 → 允许（1 股递增）。
8. 沪主板买入 150 股 → 拒绝（100 整数倍）。
9. 北交所买入 150 股 → 允许（≥100，1 股递增）。
10. 科创板卖出余额 150 股 → 一次性允许；余额 250 股拆两笔 → 拒绝第二笔零股。
11. 沪深主板风险警示股票单日累计买入 500001 股 → 拒绝；北交所 200001 股 → 拒绝。
12. 北交所盘后固定价格委托 → 拒绝（PENDING）。
13. 沪深 A 股 15:10 盘后固定价格委托 → 允许（2026-07-06 起）。
14. 14:58 撤单 → 拒绝（收盘集合竞价为不可撤）。
15. 涨停价买入委托 → 不保证成交（撮合模型返回未成交可能）。
16. 费用计算：卖出 10 万元沪市股票 → 印花税 50 元、过户费 1 元、经手费 3.41 元、证管费 2 元（不含佣金）。
17. T+1：当日买入的股票当日卖出 → 拒绝。
18. 新股：沪主板上市首日申报价超出 80%–120%（集合竞价）/64%–144%（连续竞价）→ 拒绝。
