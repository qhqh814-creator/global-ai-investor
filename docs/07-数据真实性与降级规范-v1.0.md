## 1. 核心原则

**没有真实数据时，唯一合法的状态是“数据不可用”。** 禁止任何形式的伪造、插值、随机数、示例数字、旧值冒充、默认值填充。所有外部数据必须携带溯源信息，且前端必须以用户可理解的方式展示来源与时间。

## 2. 溯源字段（所有外部数据表/API 响应必填）

| 字段 | 类型 | 说明 |
|---|---|---|
| `source_id` | string | 数据源标识，与 `data_sources` 表一致 |
| `quote_time` / `published_at` | ISO8601 | 数据自身的业务时间（不是抓取时间） |
| `fetched_at` | ISO8601 | 本次抓取时间 |
| `quote_kind` | enum | `realtime_licensed` / `delayed` / `eod_close` / `snapshot_unknown` |
| `is_realtime` | bool | **仅当 `quote_kind=realtime_licensed` 且已标定延迟时为 true**，其余一律 false |
| `delay_seconds` | int/null | 授权源标定值；未核实一律 `null`，禁止估算 |
| `license_status` | enum | `licensed` / `public_page` / `unlicensed_third_party` / `unknown` |
| `commercial_ok` | bool | 第三方未授权源为 false；发布构建禁止启用 |
| `data_unavailable_reason` | enum/null | `upstream_403` / `waf_blocked` / `nontrading_day` / `interface_deprecated` / `rate_limited` / `parse_failed` / `no_data` |

## 3. 采集器契约（每个适配器必须实现）

1. 返回 `FetchResult{records, provenance, status}`；不允许只返回裸数据。
2. 失败必须返回明确原因码，禁止吞异常返回空列表冒充“无数据”。
3. 不得用缓存旧值填充失败结果；缓存只能用于离线展示且必须标 `eod_close/STALE`。
4. 抓取时间与数据时间必须分别记录。
5. 归一化字段缺失时保留 `null`，不得补 0。
6. 所有响应样本哈希写入 `data_fetch_log`，便于排查。

## 4. 前端展示规范

### 4.1 组件

- `DataCard`：统一卡片容器，接收 `provenance`，渲染来源徽标、数据时间、状态。
- `ProvenanceBadge`：显示“来源 / 数据时间 / 实时性 / 许可状态”。
- `UnavailableState`：显示“数据不可用 / Data unavailable”+ 原因文案 + 重试。

### 4.2 文案（中英对照）

| 状态 | 中文 | English |
|---|---|---|
| 可用（第三方快照） | 第三方快照 · 数据时间 {time} · 非实时 | Third-party snapshot · {time} · not real-time |
| 可用（收盘） | 最近交易日 {date} 收盘 | Close of {date} |
| 非交易日 | 休市 · 最近交易日 {date} 收盘 | Market closed · last close {date} |
| 数据不可用 | 数据不可用（{原因}） | Data unavailable ({reason}) |
| 离线 | 当前离线，展示本地历史数据 | Offline — showing local history |
| AI 不可用 | AI 服务不可用，已暂停分析 | AI service unavailable — analysis paused |
| 加载中 | 数据加载中… | Loading data… |

### 4.3 硬性禁令

- 任何位置不得显示“实时”字样，除非 `is_realtime=true`。
- 不得显示“刚刚更新/秒级更新/实时播报”等暗示。
- 不得显示跳动动画模拟实时。
- 非交易日不得显示当日涨跌幅（应显示最近交易日并标注日期）。

## 5. 降级链（L0–L4）

| 级别 | 来源 | 条件 | UI 表现 |
|---|---|---|---|
| L0 | 授权实时源（未采购） | 默认关闭 | 不使用 |
| L1 | 东财快照（主） | 可用 | 第三方快照徽标 |
| L2 | 腾讯快照（备） | L1 失败 | 第三方快照徽标 |
| L3 | 上一交易日收盘 | L1/L2 均失败或非交易日 | “最近交易日收盘” |
| L4 | 无数据 | 全部失败 | “数据不可用（原因）” |

## 6. 校验与测试（验收必查）

### 6.1 自动化测试

1. **全源关闭测试**：禁用所有数据源 → 驾驶舱 15 张卡片全部显示“数据不可用”，无任何数字。
2. **单源失败测试**：主源 500/超时 → 自动切换备源，UI 标注正确。
3. **非法数据测试**：适配器返回 `is_realtime=true` 但 `quote_kind!=realtime_licensed` → 断言失败，拒绝入库。
4. **旧值冒充测试**：源失败时不得返回上次成功值作为当前值。
5. **非交易日测试**：显示最近交易日，不显示“实时”。
6. **缺字段测试**：缺失字段显示“—”，不得显示 0。
7. **AI 无证据测试**：AI 返回无 evidence 的结论 → 拒绝展示。
8. **发布构建测试**：包含 `commercial_ok=false` 源时构建失败。

### 6.2 人工验收

- 抽查 10 条行情/新闻/公告，逐条核对来源 URL 与时间。
- 断网启动，确认离线提示与历史数据展示。

## 7. 合规禁令

1. 不得把第三方未授权行情用于对外商业发布；V1.0 仅个人内测使用。
2. 新闻仅存标题、链接、≤100 字摘要，不存全文。
3. 公告只存元数据与原始链接，不再分发 PDF 原文。
4. 不绕过反爬、登录、验证码、WAF。
5. 发布版本必须通过“数据源许可清单”校验。

## 8. 代码级强制措施

- 数据入库 Repository 层对 provenance 字段做 `NOT NULL` + 枚举校验。
- Pydantic 模型对 `is_realtime/quote_kind/license_status` 做交叉校验。
- 前端 TypeScript 类型中 provenance 为必填；`DataCard` 无 provenance 时渲染“数据不可用”。
- 单元测试覆盖上述组合；CI 中失败即阻断。
