## 1. 目录与数据边界

| 目录 | 内容 | 是否可删除 |
|---|---|---|
| `docs\` | 基线文档 | 否（纳入 git） |
| `app\` `electron\` `backend\` `scripts\` | 源码 | 否（纳入 git） |
| `data\db\gai.db` | 主数据库 | 否（有备份） |
| `data\cache\` | 可重建缓存 | 是 |
| `data\logs\` | 日志（滚动） | 是 |
| `data\settings\` | 设置与加密密钥 | 否（有备份） |
| `backups\` | 备份归档 | 否（按策略清理） |
| `tools\` `.venv\` | 运行时依赖 | 可重建（不提交 git） |

- 所有路径通过配置根目录拼装；**禁止硬编码 C 盘路径**。
- 用户数据目录可整体迁移（设置页提供“打开数据目录”“迁移数据目录”）。

## 2. 备份策略

1. **启动备份**：每次启动前，若数据库存在且当日尚无备份，复制到 `backups/db/gai-YYYYMMDD-HHMMSS.db`（SQLite backup API）。
2. **每日备份**：调度器每日收盘后备份；保留最近 30 份，超出按时间清理。
3. **迁移前备份**：schema 迁移前强制备份。
4. **手动备份**：设置页按钮，导出 zip（数据库 + 设置；不含密钥明文）。
5. 恢复：设置页选择备份文件 → 校验完整性 → 替换数据库前再次备份当前库。

## 3. 安装、升级、卸载

| 操作 | 行为 |
|---|---|
| 安装 | NSIS 安装到用户选择目录（默认 `F:\GlobalAIInvestor` 或安装向导选择）；创建开始菜单/桌面快捷方式 |
| 升级 | 保留 `data\`；替换程序文件；迁移脚本自动执行（先备份） |
| 卸载 | 删除程序文件；**默认保留 `data\`**；提供“同时删除用户数据”勾选项（二次确认） |
| 便携运行 | 提供免安装 zip（可选），数据目录跟随程序目录 |

## 4. 密钥与隐私

- DeepSeek API Key 使用 Windows DPAPI（`CryptProtectData`，用户级）加密后存 `data/settings/secrets.dat`。
- 密钥不得出现在日志、前端、git、崩溃报告中；设置页只显示掩码。
- 不上传任何用户数据；AI 调用只发送待分析文本（新闻标题/摘要/公告片段），设置页提供“查看将要发送的内容”。
- 无遥测、无统计上报。

## 5. 日志与诊断

- 日志目录 `data/logs/`，按天滚动，保留 30 天。
- 级别：ERROR/WARN/INFO/DEBUG（默认 INFO）。
- 诊断包：设置页可导出 zip（日志 + 配置（脱敏）+ 数据库 schema 版本），仅供用户本地排查。
- 崩溃：Electron 主进程捕获未处理异常并写入日志；sidecar 崩溃由 main 重启并记录。

## 6. 代码与文档保护

1. git 仓库，分支策略：`main`（稳定）+ `dev`（开发）；提交信息规范。
2. 禁止提交：`data/`、`.venv/`、`tools/`、`node_modules/`、密钥、备份。
3. 重大变更（规则库、数据源、数据库 schema、打包配置）需变更记录（文档 09）。
4. 删除/移动文件前确认目标路径；破坏性脚本必须二次确认并支持 dry-run。
5. 不修改系统环境变量/注册表/防火墙（除用户明确授权的安装行为外）。
6. 依赖锁定：`package-lock.json`、`uv.lock`/`requirements.lock` 提交。

## 7. 打包与签名

- electron-builder NSIS；PyInstaller onedir 打包 sidecar。
- 当前无代码签名证书：安装包未签名 → SmartScreen/360 可能提示；发布说明中给出 SHA256 与“更多信息→仍要运行”指引。
- 可选：生成自签名证书用于内部测试（不作为正式发布签名）。
- 打包产物命名：`GlobalAIInvestor-Setup-<version>.exe`；同时输出 `.sha256`。

## 8. 失败恢复

| 场景 | 处理 |
|---|---|
| 数据库损坏 | 启动完整性检查（`PRAGMA integrity_check`）；失败则提示从备份恢复 |
| sidecar 无法启动 | 显示错误页、日志路径、重试按钮；不白屏 |
| 安装包被拦截 | 文档指引；提供校验值；用户加白名单后重试 |
| 升级失败 | 保留旧版本程序目录备份；支持回滚 |

## 9. 权限与运行环境

- 应用以普通用户权限运行；不需要管理员权限（安装除外）。
- 不注册系统服务；Ollama 由用户自行安装/启动，应用仅检测并通过 HTTP 调用。
- 端口：sidecar 使用随机空闲端口，仅绑定 127.0.0.1。
