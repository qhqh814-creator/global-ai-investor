## 2. 信息核验

新增 `news_verification`：

- `source_authenticity`：OFFICIAL（交易所/公司公告）、MULTI_SOURCE（多源一致）、PUBLIC_SINGLE（单一公开源）、PUBLIC_GLOBAL（全球源）、UNVERIFIED；
- `corroboration_count`：相似标题的独立来源数；
- `price_reaction`：REACTED_UP / REACTED_DOWN / MOVED_BEFORE / NO_REACTION / NO_PRICE_DATA / NO_STOCK_LINK；
- 价格反应基于 `kline_daily` 发布前后交易日涨跌幅（±2% 阈值；发布前 ≥5% 标记提前异动），仅表示关联，不证明因果；
- 当前实测：382 条已核验；由于 A 股日线只覆盖少量代码、全球新闻未绑定 A 股标的，`REACTED_*` 暂为 0——这是下一阶段要补的（补日线 + 出口行业/公司映射）。
